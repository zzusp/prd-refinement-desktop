# 任务详情资料包视图

## 目标

- 在任务详情的结果视图中增加“资料包”Tab，集中查看本次任务实际固定的资料信息。
- 展示资料包名称、固定版本、文件数、内容单元数、文件角色、读取状态、大小和本次分析说明。
- 保持该视图只读，不把资料准备页的添加、删除、改用途等编辑能力复制到任务详情。

## 数据边界

- 任务详情必须展示任务启动时的冻结快照，不能读取后来被修改或删除的当前资料包冒充任务输入。
- 新任务在 `PrdProject` 中持久化轻量的 `materialSnapshot`：资料包名称、版本、状态、更新时间、文件清单和当时的问题记录。
- 原文正文继续由既有 `sourceDocuments` / `sourceUnits` 持有；资料快照不复制正文、磁盘路径或内部文件内容。
- 旧任务没有 `materialSnapshot` 时，根据已冻结的 `sourceDocuments` 和 `sourceUnits` 降级展示，并明确提示元数据不完整。

## 交互与布局

- “资料包”与“功能与需求 / 全部需求 / 执行记录”使用同一普通按钮式视图切换，不声明未实现的 ARIA tabs 键盘模型。
- 顶部摘要先说明这是任务固定输入，再显示四项稳定指标；下方使用只读文件列表。
- 本次分析输入移入资料包视图，避免在结果区域下方形成脱离导航的重复内容。
- 文件列表在窄窗口横向滚动，不改变任务详情其他视图的滚动所有权。

## 验证

- 单元测试验证资料快照随任务项目固定、旧任务降级和资料包视图内容。
- 执行类型检查、完整测试、生产构建、UI 契约与 premium 严格审计。
- 使用真实 Electron 构建检查视图切换、长路径、无补充说明和窄窗口布局。
